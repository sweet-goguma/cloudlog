# 나만의 드라마 기록소

드라마와 영화를 포스터 카드로 등록하고, 국가별 카테고리·구름 평점·명대사·명장면·OTT 정보·감상 메모를 저장하는 정적 웹사이트 MVP입니다.

## 실행 방법

1. `index.html` 파일을 브라우저에서 엽니다.
2. `작품 추가` 버튼을 눌러 작품을 등록합니다.
3. 등록된 작품 카드를 클릭하면 상세 정보를 볼 수 있습니다.

## 포함 기능

- 작품 등록 / 수정 / 삭제
- 드라마 / 영화 카테고리
- 한국 / 중국 / 일본 / 영어권 / 기타 국가별 세부 카테고리
- 포스터 이미지 첨부 및 미리보기
- 구름 평점 1~5개
- OTT 복수 선택
- 제목, 배우, 명대사, 메모 검색
- OTT 필터
- 최근 등록순 / 구름 평점 높은 순 / 제목순 정렬
- LocalStorage 데이터 저장
- JSON 내보내기 / 가져오기
- 샘플 데이터 불러오기

## 파일 구성

- `index.html`: 화면 구조
- `styles.css`: 전체 디자인 및 반응형 UI
- `app.js`: 등록, 수정, 삭제, 필터, 저장 로직
